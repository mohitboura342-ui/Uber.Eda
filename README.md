# 🚖 Uber Trip Analysis & Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project focuses on performing **Exploratory Data Analysis (EDA)** on Uber trip data to uncover meaningful insights, travel patterns, and customer behavior trends.
The analysis was carried out using Python and popular data analytics libraries.

---

## 🎯 Objectives

* Analyze Uber trip patterns
* Identify peak booking hours and busiest days
* Understand trip distribution over time
* Discover trends through data visualization
* Generate business insights from raw data

---

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## 📊 Analysis Performed

### ✔ Data Cleaning

* Removed missing values
* Converted date/time columns
* Checked duplicate entries

### ✔ Univariate Analysis

* Trips by hour
* Trips by weekday
* Monthly trip trends

### ✔ Bivariate & Multivariate Analysis

* Relationship between trip timing and frequency
* Peak demand analysis
* Heatmaps and correlation analysis

### ✔ Data Visualization

* Countplots
* Histograms
* Heatmaps
* Line graphs
* Bar charts

---

## 📈 Key Insights

* Uber rides are highest during office commuting hours.
* Weekends show different ride behavior compared to weekdays.
* Certain hours of the day consistently experience peak demand.
* Travel activity increases significantly during evening periods.
